# Typemindmap — 左圖右文雙向同步心智圖工作台

[![Deploy to GitHub Pages](https://github.com/etsaycood/Typemindmap/actions/workflows/deploy.yml/badge.svg)](https://github.com/etsaycood/Typemindmap/actions/workflows/deploy.yml)

🔗 **線上網址**：[**https://etsaycood.github.io/Typemindmap/**](https://etsaycood.github.io/Typemindmap/)

**Typemindmap** 是一款以鍵盤極速輸入為核心、兼具圖形直接互動能力的純前端心智圖應用程式，並採用 **「左側互動心智圖畫布 + 右側縮排大綱打字區」** 雙向即時同步架構）。

所有內容 **100% 儲存在您的瀏覽器本地（LocalStorage）**，無需註冊、零伺服器上傳，打開即用。

---

## ✨ 核心特色

### 1. ⌨️ 右側：鍵盤優先縮排大綱編輯器（Keyboard-First Outliner）
- **打字速度就是繪圖速度**：第一行即根節點，按 `Enter` 自動對齊縮排建立同級節點，按 `Tab` 建立子分支，`Shift + Tab` 提升層級。
- **整塊移動子樹**：按 `Alt + ↑ / ↓` 直接將當前節點連同底下所有巢狀子項目整塊上下搬移，免剪貼重排。
- **多分頁工作區**：右側頂部支援多張圖表分頁切換、雙擊分頁重新命名、獨立儲存排版模式。
- **行內增強語法**：
  - `[ ] 任務` / `[x] 任務`：可直接在圖形上點擊打勾的待辦核取方塊
  - `#標籤`：自動渲染為彩色標籤膠囊
  - `// 補充說明`：於節點卡片下方呈現精簡備註
  - `@color(indigo|emerald|amber|purple|rose|cyan)`：指定分支主題色
  - `https://...` 或 `@url(...)`：附加可點擊外部超連結

### 2. 🧠 左側：可直接編輯的視覺化互動心智圖（Interactive Canvas）
- **100% 圖文雙向同步**：不只右邊打字會改左邊的圖，**在左邊圖形上做的任何修改也會即時寫回右邊的縮排文字**！
- **流暢建立與平滑置中**：
  - 按 `Tab` 建立子節點、按 `Enter` 建立同級節點時，輸入框保持**空白**供直接輸入；若未輸入任何文字直接離開，才會自動補上預設文字。
  - 建立新節點時，視窗會自動**平滑移動並以新節點為中心**，思路不中斷。
- **iPad 畫筆風格工具筆盒（PencilKit Capsule）**：
  - 固定於左上角搜尋按鈕旁，單擊任一節點時浮現專屬畫筆圓鈕，外圈與指示點即時反映該節點分支色彩。
  - 點擊展開精緻膠囊工具列（全部整合為精巧圖示），支援一鍵換色（收納多色調色盤）、`+子節點`、`+同級`、切換待辦、詳細資訊設定、`🎯 聚焦放大` 與刪除節點。
- **直接在圖形卡片打字**：雙擊任一節點（或選取後按 `F2` / `Space`），直接在節點方塊內輸入修改。
- **滑鼠拖曳重組（Drag & Drop）**：直接拖曳節點至其他節點上方、中央或下方，即可調整同層順序或變更父子階層。
- **📱 完整支援平板與觸控螢幕手勢（iPad / Android / 觸控筆電）**：
  - **單指自由平移**：手指在左側畫布任意處滑動皆可即時拖動畫布視角，並自動屏蔽瀏覽器原生滾動與下拉重整干擾。
  - **雙指捏合縮放（Pinch-to-Zoom）**：支援以雙指中心點為基準平滑放大縮小與移動。
  - **智慧觸控點擊判斷**：滑動手勢結束後不會誤觸節點，點擊卡片仍能秒選取或展開 iPad 風格工具筆盒。
  - **左右分割欄觸控調整**：中線分割條支援觸控手指直接拖拉調整左圖右文比例。
- **四種專業佈局一鍵切換**：
  1. `➡️ 右側邏輯圖`（由左至右水平展開）
  2. `↔️ 雙向平衡圖`（中心對稱展開）
  3. `⬅️ 左側邏輯圖`（由右至左水平展開）
  4. `⬇️ 垂直樹狀圖`（由上至下組織架構圖）

### 3. 🌐 中英雙語介面與多主題支援
- **繁體中文 / 英文 (English) 一鍵切換**：右上角提供語言切換按鈕，支援完整介面中英雙語（保留原有中文用詞，支援英文介面切換）。
- **深色 / 淺色主題切換**：右上角提供日夜間主題切換，全站適配深淺色模式。
- **本地記憶偏好**：語言偏好與主題設定自動記住在瀏覽器中。

### 4. ☁️ 雲端分享連結功能（Zero Sign-up Cloud Share）
- **免註冊·免資料庫·跨裝置開啟即用**：點擊右上角「雲端分享」按鈕，立即將心智圖發布至免費雲端，產生專屬分享網址（例如 `https://etsaycood.github.io/Typemindmap/?s=p_xxxxxx`）。
- **彈性分享範圍**：
  - **當前心智圖**：僅分享目前分頁，接收方開啟時會自動加入為新分頁，不干擾既有筆記。
  - **整個工作區**：分享所有分頁與完整排版佈局，適合專案交付或團隊討論。
- **多雲端儲存自動容錯（Multi-Provider Fallback）**：
  - 整合 `Pastes.dev` (~10 MB, 極速推薦)、`dpaste.com` (~1 MB, 保存 365 天)、`JSONBlob` (~100 KB)，依檔案大小自動推薦最佳服務與自動降級備援。
- **無縫載入與防覆蓋保護**：
  - 接收者開啟分享連結時自動於頂部顯示載入橫幅並呈現心智圖。
  - 提供「清除網址參數」按鈕，可一鍵移除網址列上的 `?s=` 參數，避免後續重新整理或儲存時誤被雲端覆蓋。

### 5. 📤 多格式無損匯出與工作區備份
- **高解析度 PNG (2x Retina)** 與 **純向量 SVG 圖檔**（純原生向量繪製，絕不掉字）
- **Markdown (`.md`)**、**Mermaid `mindmap` (`.mmd`)**、**純文字大綱 (`.txt`)**
- **JSON 完整工作區備份與還原**

## 🚀 本地啟動與開發

```bash
cd Typemindmap
npm install
npm run dev
```

建置生產環境靜態檔案（內附 GitHub Pages 自動部署 Workflow `.github/workflows/deploy.yml`）：

```bash
npm run build
```
